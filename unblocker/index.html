In-page browser

Load another site inside this one. Point it at a proxy you trust.

Proxy endpoint

Pages load through a third-party proxy. That proxy is somebody else's server — when it goes down, this page goes with it. Paste a different one here and everything keeps working, no redeploy needed. The endpoint should end where the target URL gets appended, for example https://example.com/?url=.

Worth knowing

  • Sites that refuse to be framed will still refuse. A proxy helps with most of them, not all.
  • Do not sign in to anything that matters through a proxy you do not run. Whoever owns it sees the traffic.
  • Your panic key works here too. Set it in Settings.
