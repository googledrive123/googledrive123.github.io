Backup addresses

GameVault also runs at other addresses. Schools block sites one address at a time, so when one stops working another usually still does. Bookmark a couple now, before you need them.

How it works

Every address runs the same GameVault, and each one picks up new games and fixes by itself within a day.

The dot shows whether this browser can reach an address right now: green works, red is blocked, grey did not answer in time. A school can block a different address tomorrow, so check again when one stops loading.

Progress stays with the address you played on, so a new address starts empty. Move my saves there opens that address in a new tab and copies this browser's progress across, replacing whatever progress was there before.
